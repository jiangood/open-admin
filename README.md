# open-admin

![Maven Central](https://img.shields.io/maven-central/v/io.github.jiangood/open-admin)

open-admin 是一个小型管理系统框架（后台管理脚手架），提供用户管理、角色权限、数据字典、作业调度（Quartz）、文件管理、流程引擎等功能。

## 文档

完整文档请参阅 **[docs/index.md](docs/index.md)**，包含：

- **快速开始**：[docs/quick-start.md](docs/quick-start.md) — 环境搭建和基础使用
- **核心功能**：用户权限、数据字典等
- **API 参考**：前后端组件、工具类、注解
- **开发指南**：编码规范、最佳实践

## 核心功能

1. **用户权限管理**：完整的用户、角色、权限体系
2. **数据字典管理**：统一的数据字典维护和使用
3. **作业调度**：基于 Quartz 的定时任务管理
4. **文件管理**：统一的文件上传、存储和管理
5. **系统配置**：灵活的系统参数配置
6. **操作日志**：完整的操作日志记录
7. **流程引擎**：内置工作流引擎，支持自定义流程
